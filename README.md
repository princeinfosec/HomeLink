# HomeLink

HomeLink is a responsive React/TanStack Start housing marketplace UI for verified rentals, roommates and direct owner conversations.

## Project map

- **Frontend:** [`src/homelink`](src/homelink) — components, views, context, data, services and styles
- **Backend integration:** [`src/homelink/services/api.js`](src/homelink/services/api.js) — centralized API client
- **Backend guide:** [`backend/README.md`](backend/README.md) — the backend server is external to this package
- **Full structure:** [`docs/PROJECT-STRUCTURE.md`](docs/PROJECT-STRUCTURE.md)

## Development

```sh
pnpm install
pnpm run dev
```

For a production build:

```sh
pnpm run build
```

## Stack

TanStack Start, React, TypeScript, Tailwind CSS and a centralized HomeLink API client.
